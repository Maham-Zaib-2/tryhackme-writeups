# Defensive Security Intro

**Path:** Pre Security > Introduction to Cyber Security
**Platform:** TryHackMe

## Goal
Play the role of a defender and stop a hacker in a simulated security dashboard.

## What I did
1. Watched the defender's dashboard until an alert appeared.
2. Checked the IP address behind the alert.
3. Looked at which sites that IP was trying to open.
4. Blocked the IP, slowed down its activity, and turned the protection on.

## What I learned
- Defenders spend their time spotting alerts and deciding whether they are real threats.
- Checking the IP and what it is trying to access helps show if it is an attacker.
- Blocking and rate limiting (slowing down activity) are simple ways to stop an attack.

## Key idea
This was the other side of the last room. Attackers look for weaknesses, and defenders watch for them and respond quickly.
