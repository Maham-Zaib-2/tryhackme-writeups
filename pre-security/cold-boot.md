# Cold Boot

**Path:** Pre Security
**Platform:** TryHackMe

## Goal
A workstation was pulled from a breach scene in pieces. Rebuild it, boot it, find the evidence file, and email it to the senior analyst to close the case.

## What I did
1. Read the case file and looked at the recovered parts.
2. Picked the correct parts to assemble the machine, since some of the parts didn't belong to it.
3. Booted the machine and found the evidence file.
4. Answered questions about what each part does and how it connects to the motherboard.
5. Wrote an email to the senior analyst with my findings.

## What I learned
- Knowing what each computer part does helps you spot which ones belong together.
- Forensics means collecting evidence carefully from a machine after an incident.
- Reporting matters. Finding the evidence is only half the job, and you also have to explain it clearly to someone else.

## Key idea
This was my first forensics lab. It showed me that investigators need to understand hardware as well as software.
